# personal-site

Peter Radavich's personal website. Plain HTML + CSS, no build step.

## Preview locally

```sh
python3 -m http.server 8080
# open http://localhost:8080
```

## Structure

- `index.html` — the page
- `assets/style.css` — styles (light/dark via `prefers-color-scheme`)

Search for `TODO` to find spots to personalize.
